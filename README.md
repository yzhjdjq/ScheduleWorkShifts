# График смен (Schedule Work Shifts, SWS)
Приложение позволяет показывать рабочие смены на календаре.

## Основные функции
 - Создание нескольких расписаний
 - Создание нескольких рабочих смен с возможностью настройки их имени и цвета на календаре
 - Поддержка настройки расписания с несколькими сменами подряд 
 - Поддержка отображения как одного расписания, так и двух в режиме сравнения
 - Виджет рабочего стола на Android, отображающий выбранное расписание

## Поддерживаемые платформы
 - Android (minimum Android 8)
 - Linux (x64, flatpak package)
 - Aurora (x86_64, Aurora 5.1)

## Руководство пользователя
### Первый запуск
При первом запуске приложения можно наблюдать главный экран, приведенный ниже.

![Первый запуск](./doc/images/Первый%20запуск.png)

> Модуль статистики не реализован, поэтому значение рабочих дней будет постоянным.

### Настройка графиков

Для добавления графиков необходимо открыть боковое меню

![Боковое меню](./doc/images/Боковое%20меню.png)

И перейти из него на страницу настроек

![Общие настройки](./doc/images/Общие%20настройки.png)

Затем открыть "настройки графиков". На ней будет показан список существующих графиков.
Основные операции:
- Добавление графика
	- нажать плавающую кнопку в правом нижнем углу страницы
- Изменение графика
	- нажать на интересующий график в списке
- Удаление графика
	- нажать и удерживать интересующий график в списке до появления всплывающего меню удаления.

Ниже приведен скриншот всплывающего окна создания графика. На нем видно это самое окно 
создания/редактирования графика, а также кнопку добавления графика внизу страницы.

![Настройки графиков](./doc/images/Всплывающее%20окно%20создания%20и%20редактирования%20графика.png)

### Настройка рабочих смен

Для добавления рабочих смен нужно перейти в пункт "настройка смен". 
Его функциональность аналогична настройке графиков:
 - Добавление смены
	- нажать плавающую кнопку в правом нижнем углу страницы
- Изменение смены
	- нажать на интересующую смену в списке
- Удаление смены
	- нажать и удерживать интересующую смену в списке до появления всплывающего меню удаления.

> В списке смен есть постоянные пункты "отпуск" и "больничный". 
> У них нельзя изменить название и удалить из списка смен.

Для изменения цвета смены необходимо двигать ползунки "цвет", 
"насыщенность" и "яркость" до получения желаемого результата.

> Категория рабочей смены "рабочий день" и "выходной" нужны 
> для статистического анализа графика смены, который пока не реализован.

![Настройки смен](./doc/images/Всплывающее%20окно%20создания%20и%20редактирования%20смены.png)
### Настройка расписания в графике

Для создания (настройки) расписания в графике необходимо выполнить ранее описанные процедуры их создания 
(настройка графика и настройка рабочей смены). После этого из бокового меню можно перейти на страницу 
создания графика по одноименному пункту. Ниже приведен начальный вид этой страницы.

![Создание графика](./doc/images/Страница%20создания%20и%20редактирования%20графика.png)

На ней в выпадающем списке выбирается график, расписание которого будет создаваться (настраиваться). 
Затем устанавливается дата, начиная с которой в календаре будет производится статистический анализ 
и окрашивание дней. Далее идет таблица, в которой настраивается порядок смен в расписании. В первом столбце 
при помощи выпадающего списка выбираются рабочие смены в нужном порядке. Во втором столбце указывается 
количество дней в течение которых выбранная смена будет идти подряд. Аналогичного результата можно добиться 
если настроить несколько строк с одинаковыми сменами с количеством дней повтора по умолчанию (1). 
В последнем столбце настраивается рабочее время. Оно необходимо для статистического анализа, 
который пока не реализован. Поэтому его указание не обязательно. Внизу страницы находятся две кнопки: 
добавления смены в таблицу с расписанием и сохранения расписания. Когда в таблице с расписанием более 
трёх строк, то есть возможность удалить некоторые из них при помощи кнопки в 4-м столбце с красной иконкой корзины.

![Создание графика 2](./doc/images/Страница%20создания%20и%20редактирования%20графика%202.png)

После сохранения настроек, произведенных для двух графиков на главной странице автоматически обновится календарь.

![Нормальный режим отображения графика](./doc/images/Нормальный%20режим%20отображения%20графика.png)

### Настройка отображения графиков на календаре

По умолчанию включен одиночный просмотр расписания первого графика.

![Нормальный режим отображения графика](./doc/images/Нормальный%20режим%20отображения%20графика.png)

Для управления режимом отображения используется иконка календаря в заголовке странице справа. 
При нажатии на нее появляется всплывающее окно выбора расписания для отображения

![Всплывающее окно выбора графика](./doc/images/Всплывающее%20окно%20выбора%20графика.png)

Для смены нужно отображаемого расписания нужно нажать на интересующий график. 
Также доступен режим сопоставления графиков, в котором отображаются два графика одновременно. 
Для перехода в этот режим нужно выбрать последний одноименный пункт в открытом всплывающем окне.

![Всплывающее окно сопоставления графиков](./doc/images/Всплывающее%20окно%20сопоставления%20графиков.png)

В новом всплывающем окне настройки сопоставления графиков есть два выпадающих списка. 
Первый график занимает верхнюю левую половину ячейки дня, а второй - нижнюю правую. 
Для смены порядка используется кнопка со стрелками между выпадающими списками. 
Для сохранения настроек необходимо нажать кнопку "сопоставить". После этого откроется 
обновленный календарь, показанный ниже.

> В режиме сопоставления виджет рабочего стола Android отображает расписания первого графика в одиночном режиме.

![Режим сопоставления графиков](./doc/images/Режим%20сопоставления%20графиков.png)

### Настройка отпуска и больничного

Для работы с отпуском и больничным необходимо отключить режим сопоставления графиков, 
выбрав один отображаемый график. Именно для него и будет производиться добавление 
и удаление отпуска и больничного.

Для добавления отпуска или больничного необходимо открыть боковое меню и нажать на соответствующий пункт 
"Отпуск" или "Больничный". После этого откроется всплывающее окно, в котором необходимо выбрать дату начала 
и завершения настраиваемого периода. После этого нажать кнопку "Добавить". Окно закроется, а на календаре 
обновиться раскраска.

![Всплывающее окно добавления отпуска](./doc/images/Всплывающее%20окно%20добавления%20отпуска.png)

Для удаления отпуска и больничного необходимо нажать на интересующий период в календаре. 
Откроется всплывающее окно с обозначением его даты начала и завершения. В нем будет кнопка "Удалить". 
При ее нажатии период отпуска или больничного будет удален.

> Для изменения периода отпуска или больничного сначала удалите неправильный, а затем создайте новый с нужными датами начала и завершения.

![Отображение отпуска в нормальном режиме](./doc/images/Отображение%20отпуска%20в%20нормальном%20режиме.png)

### Навигация в календаре

Для навигации в календаре на главной странице приложения используется блок под заголовком страницы, 
находящийся над легендой календаря (если включена в настройках).
 - для перехода к следующему месяцу необходимо нажать на стрелочку ">" в правой части блока.
 - для перехода к предыдущему месяцу необходимо нажать на стрелочку "<" в левой части блока.
 - для перехода к текущей дате нажать на центр блока по тексту названия отображаемого в календаре месяца и года.

> Навигация в календаре виджета рабочего стола Android не доступна.
